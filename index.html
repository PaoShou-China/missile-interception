仿真链路Simulation pipeline

从发射到交会，每个环节都有独立模块与对应测试。From launch to intercept, every stage has its own module and tests.

组合动力Combined cycle

固体助推接力超声速冲压，推力与耗量随高度、马赫数调度。Solid booster hands over to a supersonic ramjet, with thrust and flow scheduled by altitude and Mach.

GNSS/INS 组合导航、雷达导引头量测、目标跟踪与滤波。GNSS/INS integration, radar seeker measurements, target tracking and filtering.

三回路自动驾驶仪、舵机限幅与速率约束、增益调度。Three-loop autopilot, actuator deflection and rate limits, gain scheduling.

多速率积分Multi-rate integration

不同飞行段自适应步长与事件处理，支持收敛性外推。Stage-dependent adaptive steps and event handling, with convergence extrapolation.

快速开始Quick start

克隆仓库后在 missile_intercept/ 下运行。Clone the repository and run from missile_intercept/.

$ missile_intercept/ 
# install dependencies / 安装依赖
python -m pip install -r requirements.txt

# single run / 单发仿真（输出遥测 CSV 与图表）
python main.py

# Monte-Carlo campaign / 蒙特卡洛打靶
python batch.py --cases 50 --workers 8 --seed 2026

# tests and verification / 测试与数值验证
python -m pytest -n auto
python verification.py
