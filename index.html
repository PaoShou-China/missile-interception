快速开始

克隆仓库后在 missile_intercept/ 下运行。

$ missile_intercept/ 
# 安装依赖
python -m pip install -r requirements.txt

# 单发仿真（输出遥测 CSV 与图表）
python main.py

# 蒙特卡洛打靶
python batch.py --cases 50 --workers 8 --seed 2026

# 测试与数值验证
python -m pytest -n auto
python verification.py
