# 6-DoF 高保真升级计划

目标：把当前“3-DoF 质心 + 6-DoF 运动学姿态”的末段解算，升级为**力与力矩同时积分、舵机/DACS 在环、可分级、可用数据验证**的刚体六自由度模型。

“保真度高”在这里拆成三级，逐级设验收门：

| 级别 | 内容 | 数据依赖 | 用途 |
| --- | --- | --- | --- |
| F1（现状） | 3-DoF 质心 + 运动学姿态 + 工程气动表 | 无 | 演示、参数趋势 |
| F2 工程 6-DoF | 刚体动力学、气动力矩、舵机二阶模型、X 舵混控、分级质量 | 估算惯量/铰链力矩/舵机参数 | 控制律设计、闭环演示 |
| F3 验证 6-DoF | 验证气动（CFD/风洞）、DACS 模型、传感器误差、蒙特卡洛 | DATCOM/CFD/风洞 + 实测弹道 | 可信性能评估 |

计划按 F2 → F3 推进；F3 的气动与 DACS 数据必须外部提供，无法从公开渠道获得。

### 实施状态（当前）

已落地 **F2 工程 6-DoF**（`src/sim/sixdof.ts`，默认启用，可切回简化 3-DoF）：

- 阶段 2：四元数运动学 + 欧拉方程 + RK4 1 ms，球面引力/指数大气；dt 1 ms vs 0.5 ms 终端位置差 0.000%。
- 阶段 3：一阶舵机（行程/速率/带宽限幅）、skid-to-turn 速率回路、**DACS 直接力分配**（舵面按静稳定裕度可配平的 α/β 上限分配，余量由 30 g 直接力补足，含冲量预算统计）。发现并修正了两处符号/建模错误：偏航速率指令符号（β̇≈−r），以及把气动表的 `Cnδ`（法向力导数）误当作偏航力矩导数（偏航现与俯仰对称，用 `|Cmδ|` 与 `Cm(β)`）。
- 验收：`scripts/validate_6dof.mjs` 11/11（收敛、拦截 1 m、角速率 ≤0.78 rad/s、α≤7.4°、β≤10.5°、舵偏 ≤13.9°、无持续饱和、17.2 g、DACS 620 m/s）；`validate_app` 24/24。
- 未完成（F3）：铰链力矩、舵机间隙/死区、DACS 推力/比冲实测、惯量实测、验证气动、JSBSim 互验与蒙特卡洛（阶段 4/5）。

## 阶段 0：基线统一与数据模型（先决条件）

1. **确定代表型号**：Block IB（1501 kg，6.55 m，0.34 m）还是当前 payload 的 2565 kg 合成弹。两者不能混用；建议以 Block IB 为准，把 payload 质量曲线改成一致的分级质量。
2. **建立参数包** `src/sim/6dof/vehicle.json`：几何、质量/重心/惯量随时间的表、级间时序、推力曲线、气动表引用、舵机/DACS 参数、导引头参数。所有字段带 `source`（public / estimate / test）与不确定度。
3. **坐标系与单位固定**：ECEF/ENU、BODY（x 前/y 右/z 下）、四元数、SI 单位；写一份符号约定，避免气动系数与力矩符号错位。
4. **状态量定义**：r、v、q（BODY→ECEF）、ω、m、惯量张量、舵偏、DACS 剩余冲量。
5. **验收门 G0**：参数包能被解析、单位/符号自检通过；选型决策记录在案。

## 阶段 1：气动数据（决定保真度上限）

1. **几何冻结**：从 GLB/Blender 导出参考面积、平均气动弦、尾翼平面形状、铰链线位置；补齐助推器尾翼（当前 GLB 缺失，公开翼展 ~1.57 m）。
2. **生成/获取系数表**（Mach 0.3–12 × α −10…20° × β −10…10°）：
   - 首选 Missile DATCOM / Digital DATCOM 做部件组合；
   - 用 SU2/OpenFOAM 做关键点校核（跨音速、大攻角）与强迫振动阻尼导数；
   - 有条件时用风洞补跨音速段与铰链力矩。
3. **必须补齐的系数**：CA、CN、CY、CM、Cn、Cl，Cmq/Cnr/Clp，CNδ/CMδ/Clδ，**铰链力矩 Ch**，以及雷诺数/高度修正。
4. **不确定度量化**：给每个系数一个 ±band（例如 CNα ±10%，CMα ±15%，阻尼 ±25%），进入蒙特卡洛。
5. **验收门 G1**：气动表通过对称性/单调性/连续性/量级检查（现有 28 项脚本扩展），并与至少一组公开通用导弹数据做趋势比对；铰链力矩表存在。

## 阶段 2：刚体动力学核心

1. 用四元数运动学 + 欧拉方程替换现有平动积分：
   `m dv/dt = T + A + mg`，`I dω/dt + ω×Iω = M_aero + M_control`，`dq/dt = 0.5 q⊗ω`。
2. 质量/惯量随时间变化（推进剂消耗、分级分离、KW 弹射），重心随质量移动。
3. 积分器：RK4，固定步长 1 ms；提供 0.5 ms 对照用于收敛检查。长航时（助推+中段）可切自适应步长。
4. 环境：标准大气、球面引力；全程仿真时加地球自转/科氏项。
5. **验收门 G2**：
   - 无控弹道 vs 解析解（真空抛体、纯阻力）误差 < 0.5%；
   - 时间步减半后轨迹差 < 0.5%；
   - 能量/动量闭合（无推力、无气动时）漂移 < 1e-6 相对；
   - 与 JSBSim 同构模型代码对代码比对，终端状态差 < 1%。

## 阶段 3：执行机构与控制闭环

1. **舵机模型**：二阶（ωn、ζ）＋速率限幅＋行程限幅＋传输延迟＋死区/间隙；参数默认 ±15°、200 °/s、10 Hz、ζ=0.7、延迟 5 ms，全部可配。
2. **X 型四舵混控**：俯仰/偏航/滚转指令 → 四片舵偏；含舵效随 Mach 变化。
3. **自动驾驶仪**：速率/过载回路（或动态逆），限幅与抗饱和；给出穿越频率/相位裕度指标。
4. **DACS（动能弹头段）**：4 个姿轨控 + 6 个姿态喷口，含最小冲量、阀门延迟、剩余推进剂；与气动舵按动压分配（高空用 DACS，低空用舵）。
5. **验收门 G3**：
   - 舵机阶跃响应与给定二阶模型误差 < 5%；
   - 闭环阶跃过载指令：超调 < 10%、调节时间符合设计指标；
   - 饱和/抗饱和无积分风up；DACS 冲量预算闭合。

## 阶段 4：制导、导引头与误差源

1. 制导：PN → 可选 APN/最优制导；导航比可调；终端视线角约束。
2. 导引头：FOV、锁定距离、跟踪时间常数、角噪声、盲区；与弹体运动耦合（隔离度）。
3. 误差源：初始状态误差、气动偏差、推力偏差、风、舵机零位、传感器噪声；全部进蒙特卡洛。
4. **验收门 G4**：单发标称弹道与记录 payload 的前缀吻合（位置/速度 RMSE 在设定阈值内）；100 发蒙特卡洛给出脱靶量分布（CEP/90%），并与工程预期一致。

## 阶段 5：验证与不确定度报告

1. **验证金字塔**：解析解 → 代码对代码（JSBSim）→ 与记录弹道比对 → 蒙特卡洛统计。
2. **F3 验收门 G5**：
   - 关键状态量（速度、高度、攻角、过载）与参考数据相对误差 < 5%（除跨音速段）；
   - 脱靶量分布的中位数/90% 分位与预期区间一致；
   - 所有系数带来源与不确定度，报告可复现。
3. 输出 `docs/6DOF-VALIDATION.md`：模型假设、参数来源、收敛性、比对曲线、蒙特卡洛结果、已知偏差。

## 阶段 6：产品化与界面

1. 解算面板增加“6-DoF（工程）/ 6-DoF（验证）/ 简化”三档；不可用档位灰显并说明缺什么数据。
2. 遥测面板增加：攻角/侧滑角、三轴角速率、舵偏、DACS 剩余冲量、铰链力矩（若有）。
3. 图表增加 α/β、ω、舵偏、过载曲线。
4. 方法面板与 README 同步模型边界；保留“记录数据 vs 解算数据”的明确标识。

## 保真度验收指标（汇总）

| 指标 | 目标 |
| --- | --- |
| 积分收敛 | dt 减半后终端状态差 < 0.5% |
| 守恒性 | 无外力时能量/动量漂移 < 1e-6/步长归一 |
| 解析解 | 真空/纯阻力弹道误差 < 0.5% |
| 代码互验 | 与 JSBSim 同构模型终端差 < 1% |
| 舵机模型 | 阶跃响应与给定二阶模型误差 < 5% |
| 闭环品质 | 过载阶跃超调 < 10%，无持续饱和 |
| 气动表 | 对称/单调/连续/量级检查全过，含不确定度带 |
| 记录比对 | 标称弹道关键量 RMSE 在设定阈值内（按数据质量定） |
| 蒙特卡洛 | 脱靶量分布可复现，给出中位数与 90% 分位 |

## 需要的输入（按优先级）

1. **选型决策**：Block IB（1501 kg）还是 2565 kg 合成弹。
2. **质量特性**：分级质量、重心行程、惯量张量（称重/CFD 质量特性；没有则用细长体估算并标注不确定度）。
3. **舵机参数**：行程、速率、带宽、延迟、间隙（厂家手册或实测；默认值见阶段 3）。
4. **DACS 参数**：推力、比冲、最小冲量、推进剂质量（不公开则用等效过载预算）。
5. **气动数据**：DATCOM/CFD/风洞结果（没有则用现有工程表，F2 封顶）。
6. **验证数据**：至少一条完整弹道或风洞测点，用于 G4/G5。

## 风险与对策

| 风险 | 对策 |
| --- | --- |
| 气动数据不可得，保真度封顶在 F2 | 明确分级；把 F2 标为“工程 6-DoF”，不宣称验证 |
| 惯量/重心靠估算 | 给出估算公式与不确定度，做敏感性分析 |
| 舵机/DACS 参数缺失 | 用参数化模型 + 蒙特卡洛覆盖合理区间 |
| 记录 payload 质量/推力与公开数据冲突 | 阶段 0 先统一；冲突写进方法面板 |
| 全弹道 6-DoF 计算量大 | 终端闭环用 RK4 1 ms；全弹道用自适应步长 + 事件检测（分级点） |

## 建议实施顺序

阶段 0 → 1（并行获取数据）→ 2 → 3 → 4 → 5 → 6。
阶段 2/3 可在阶段 1 的数据到位前先用现有工程气动表跑通（F2）；G1 通过后再切换验证气动（F3），无需改动动力学核心。
