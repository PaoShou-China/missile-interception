# 6-DoF 高保真升级计划

目标：把当前“3-DoF 质心 + 6-DoF 运动学姿态”的末段解算，升级为**力与力矩同时积分、舵机/DACS 在环、可分级、可用数据验证**的刚体六自由度模型。

“保真度高”在这里拆成三级，逐级设验收门：

| 级别 | 内容 | 数据依赖 | 用途 |
| --- | --- | --- | --- |
| F1（现状） | 3-DoF 质心 + 运动学姿态 + 工程气动表 | 无 | 演示、参数趋势 |
| F2 工程 6-DoF | 刚体动力学、气动力矩、舵机二阶模型、X 舵混控、分级质量 | 估算惯量/铰链力矩/舵机参数 | 控制律设计、闭环演示 |
| F3 验证 6-DoF | 验证气动（CFD/风洞）、DACS 模型、传感器误差、蒙特卡洛 | DATCOM/CFD/风洞 + 实测弹道 | 可信性能评估 |

计划按 F2 → F3 推进；F3 的气动与 DACS 数据必须外部提供，无法从公开渠道获得。

### 实施状态（当前）

已落地 **F2 工程 6-DoF**（`src/sim/sixdof.ts`，默认启用，可切回简化 3-DoF）：

- 阶段 2：四元数运动学 + 欧拉方程 + RK4 1 ms，球面引力/指数大气；dt 1 ms vs 0.5 ms 终端位置差 0.000%。
- 阶段 3：一阶舵机（行程/速率/带宽限幅）、skid-to-turn 速率回路、**DACS 直接力分配**（舵面按静稳定裕度可配平的 α/β 上限分配，余量由 30 g 直接力补足，含冲量预算统计）。发现并修正了两处符号/建模错误：偏航速率指令符号（β̇≈−r），以及把气动表的 `Cnδ`（法向力导数）误当作偏航力矩导数（偏航现与俯仰对称，用 `|Cmδ|` 与 `Cm(β)`）。
- 验收：`scripts/validate_6dof.mjs` 11/11（收敛、拦截 1 m、角速率 ≤0.78 rad/s、α≤7.4°、β≤10.5°、舵偏 ≤13.9°、无持续饱和、17.2 g、DACS 620 m/s）；`validate_app` 24/24。
- 未完成（F3）：铰链力矩、舵机间隙/死区、DACS 推力/比冲实测、惯量实测、验证气动、JSBSim 互验与蒙特卡洛（阶段 4/5）。

## 阶段 0：基线统一与数据模型（先决条件）

1. **确定代表型号**：Block IB（1501 kg，6.55 m，0.34 m）还是当前 payload 的 2565 kg 合成弹。两者不能混用；建议以 Block IB 为准，把 payload 质量曲线改成一致的分级质量。
2. **建立参数包** `src/sim/6dof/vehicle.json`：几何、质量/重心/惯量随时间的表、级间时序、推力曲线、气动表引用、舵机/DACS 参数、导引头参数。所有字段带 `source`（public / estimate / test）与不确定度。
3. **坐标系与单位固定**：ECEF/ENU、BODY（x 前/y 右/z 下）、四元数、SI 单位；写一份符号约定，避免气动系数与力矩符号错位。
4. **状态量定义**：r、v、q（BODY→ECEF）、ω、m、惯量张量、舵偏、DACS 剩余冲量。
5. **验收门 G0**：参数包能被解析、单位/符号自检通过；选型决策记录在案。

## 阶段 1：气动数据（决定保真度上限）

1. **几何冻结**：从 GLB/Blender 导出参考面积、平均气动弦、尾翼平面形状、铰链线位置；补齐助推器尾翼（当前 GLB 缺失，公开翼展 ~1.57 m）。
2. **生成/获取系数表**（Mach 0.3–12 × α −10…20° × β −10…10°）：
   - 首选 Missile DATCOM / Digital DATCOM 做部件组合；
   - 用 SU2/OpenFOAM 做关键点校核（跨音速、大攻角）与强迫振动阻尼导数；
   - 有条件时用风洞补跨音速段与铰链力矩。
3. **必须补齐的系数**：CA、CN、CY、CM、Cn、Cl，Cmq/Cnr/Clp，CNδ/CMδ/Clδ，**铰链力矩 Ch**，以及雷诺数/高度修正。
4. **不确定度量化**：给每个系数一个 ±band（例如 CNα ±10%，CMα ±15%，阻尼 ±25%），进入蒙特卡洛。
5. **验收门 G1**：气动表通过对称性/单调性/连续性/量级检查（现有 28 项脚本扩展），并与至少一组公开通用导弹数据做趋势比对；铰链力矩表存在。

## 阶段 2：刚体动力学核心

1. 用四元数运动学 + 欧拉方程替换现有平动积分：
   `m dv/dt = T + A + mg`，`I dω/dt + ω×Iω = M_aero + M_control`，`dq/dt = 0.5 q⊗ω`。
2. 质量/惯量随时间变化（推进剂消耗、分级分离、KW 弹射），重心随质量移动。
3. 积分器：RK4，固定步长 1 ms；提供 0.5 ms 对照用于收敛检查。长航时（助推+中段）可切自适应步长。
4. 环境：标准大气、球面引力；全程仿真时加地球自转/科氏项。
5. **验收门 G2**：
   - 无控弹道 vs 解析解（真空抛体、纯阻力）误差 < 0.5%；
   - 时间步减半后轨迹差 < 0.5%；
   - 能量/动量闭合（无推力、无气动时）漂移 < 1e-6 相对；
   - 与 JSBSim 同构模型代码对代码比对，终端状态差 < 1%。

## 阶段 3：执行机构与控制闭环

1. **舵机模型**：二阶（ωn、ζ）＋速率限幅＋行程限幅＋传输延迟＋死区/间隙；参数默认 ±15°、200 °/s、10 Hz、ζ=0.7、延迟 5 ms，全部可配。
2. **X 型四舵混控**：俯仰/偏航/滚转指令 → 四片舵偏；含舵效随 Mach 变化。
3. **自动驾驶仪**：速率/过载回路（或动态逆），限幅与抗饱和；给出穿越频率/相位裕度指标。
4. **DACS（动能弹头段）**：4 个姿轨控 + 6 个姿态喷口，含最小冲量、阀门延迟、剩余推进剂；与气动舵按动压分配（高空用 DACS，低空用舵）。
5. **验收门 G3**：
   - 舵机阶跃响应与给定二阶模型误差 < 5%；
   - 闭环阶跃过载指令：超调 < 10%、调节时间符合设计指标；
   - 饱和/抗饱和无积分风up；DACS 冲量预算闭合。

## 阶段 4：制导、导引头与误差源

1. 制导：PN → 可选 APN/最优制导；导航比可调；终端视线角约束。
2. 导引头：FOV、锁定距离、跟踪时间常数、角噪声、盲区；与弹体运动耦合（隔离度）。
3. 误差源：初始状态误差、气动偏差、推力偏差、风、舵机零位、传感器噪声；全部进蒙特卡洛。
4. **验收门 G4**：单发标称弹道与记录 payload 的前缀吻合（位置/速度 RMSE 在设定阈值内）；100 发蒙特卡洛给出脱靶量分布（CEP/90%），并与工程预期一致。

## 阶段 5：验证与不确定度报告

1. **验证金字塔**：解析解 → 代码对代码（JSBSim）→ 与记录弹道比对 → 蒙特卡洛统计。
2. **F3 验收门 G5**：
   - 关键状态量（速度、高度、攻角、过载）与参考数据相对误差 < 5%（除跨音速段）；
   - 脱靶量分布的中位数/90% 分位与预期区间一致；
   - 所有系数带来源与不确定度，报告可复现。
3. 输出 `docs/6DOF-VALIDATION.md`：模型假设、参数来源、收敛性、比对曲线、蒙特卡洛结果、已知偏差。

## 2. 决策点 A：端段飞行体（已用记录数据复核，结论修正）

**记录实测**（`scenario.json`）：锁定 16.1 km、qbar 626 kPa；拦截前 14.0 km、qbar 873 kPa、Mach 9.4；
质量 1100–1122 kg；记录过载 10–12 g。**端段全程在稠密大气内**，是三级弹体，不是外大气层 KW。

因此 50 kg KW + SDACS 的模型**不适用于本场景**——在 873 kPa、Mach 9.4 下用一个 1 m 长、50 kg 的
外大气层拦截器既不符合质量连续性，也会让气动力/惯量完全失真。

| 方案 | 质量 | 直接力 | 结果 | 结论 |
| --- | --- | --- | --- | --- |
| **A1 保持记录弹体 + 修正 CN（推荐）** | 1100 kg | **关闭**（本场景无 DACS） | 修正 CN 后舵面可拉 ~10 g → 可拦截 | 唯一与本场景物理一致的方案 |
| A2 端段切换 KW 50 kg | 50 kg | 20 kN → 20–40 g | “可拦截”，但与 14 km 大气段矛盾 | **不适用**（外大气层模型误用） |
| A3 保留 30 g 等效过载 | 1100 kg | 等效 330 kN | 可拦截但差 ~17× | 仅可作演示对比，需显著标注 |

**修正后的推荐 A1 + P2**：
1. `divertMaxG = 0`（本场景关闭直接力）；仅当高度 > 40 km 的端段（真正的 KW 段）才启用 4×5 kN。
2. 气动表 CN 偏低：由 `CN = m·a/(qbar·S)` 反算，锁定时段需 CN≈1.9、拦截段需 CN≈1.6（α≈10–14°）
   才能产生 10–12 g；现有表 CN(14°)≈1.05@M9，约低 **1.6–1.8×**。
3. **按同一比例 s≈1.7 同时缩放 CN 与 CM（含 CNδ/CMδ）**，保持静稳定裕度 0.78 m 和配平角不变，
   升力随 s 增大到 ~10 g；若只放大 CN 会让静稳定裕度骤降、配平与横滚耦合失真。缩放后需重新
   标定自动驾驶增益并重跑 `validate_aero` / `validate_6dof`。
4. 修正后舵面可在静稳定裕度内配平并拉出 ~10 g，**无需虚构 330 kN 直接力**，且与记录过载一致。
5. 若修正后仍达不到记录过载，则说明记录 payload 本身偏乐观，应按物理结果报告脱靶，而不是加直接力掩盖。

> A2 仍保留为“外大气层 KW 端段”的独立模式（高度 > 40 km 时启用），但**不作为本场景默认**。

### A1 实测结果（已跑通，暴露下一层问题）

按 A1 落地后（`divertMaxG=0`、`aeroScale=2.2`、`smScale=1`、AoA/β 积分 + 速率回路）：

| 指标 | 结果 |
| --- | --- |
| 稳定性 | 通过：角速率 ≤0.48 rad/s、α≤3.4°、β≤7.8°、舵偏 ≤10.6°、无持续饱和 |
| 脱靶（validate_6dof 记录几何） | **≈2.34 km**（原 divert 版 1 m） |
| 脱靶（app 默认几何，扫掠） | 2.3–27 km，全部为脱靶 |
| 结论 | 自动驾驶**无法跟踪 PN 需求**：α 只到 3–4°（约 5 g），而记录需要 10–12 g；提高增益/积分后 β 发散 |

**根因**：现有“速率回路 + α/β 分配”是简化设计，在 0.78 m 大静稳定裕度、±15° 舵限下无法稳定输出持续 10 g。
这不是加一点缩放能解决的，需要**重设计自动驾驶**（法向过载控制器 / 动态逆 + 解耦 + 抗饱和），或采用更小的静稳定裕度并重新配平。

**动态逆（DI）试验**：已把速率回路换成 `δ=(I·ω̇_des+ω×Iω−M_aero)/M_δ` 的力矩反解，并做矢量级诊断。
结果：稳定但**仍脱靶 ~2.7 km**；关键证据是**实测气动加速度与 PN 指令近乎反向**（cos≈−0.5…−0.8），且 α/β 朝 `aDes/bDes` 的反方向走。这不是增益问题，而是**气动/姿态链的坐标系-符号不一致**（α→升力方向、β→侧力方向、q/r→α/β 运动学至少有一处反了）。下一步应是逐项符号审计（forced-state 单元测试），而不是继续调参。

**法向过载反馈自动驾驶（已实现）**：外环直接以实测机体气动加速度 `az,ay` 与 PN 指令 `aTarget` 的误差产生角速率指令，内环仍用动态逆出力矩。结果：
- **方向问题已修正**：矢量日志 `cos(cmd,acc)` 从 −0.5…−0.8 变为 **+0.4…+0.8**，气动加速度与指令同向；
- 稳定通过 11/11：ω≤0.81 rad/s、α≤9.1°、β≤11.2°、舵≤13.9°、无持续饱和；
- 但脱靶仍 **≈1.68 km**：实测只能拉到 ~11 g，而 PN 因初始跟不上很快升到 40 g；把 accGain 从 0.005 提到 0.008 以上就发散（ω>9 rad/s）。**带宽-稳定裕度**与**气动能力**同时卡住，纯气动在当前几何与气动表下无法复现记录命中。

**结论**：A1 的瓶颈已从“方向/符号”转为“气动能力 + 控制带宽”。要继续必须至少满足一项：更高且经 CFD/风洞确认的 CN（如 CN(14°)→2 以上）、更大的舵/控制裕度（减小静稳定裕度或加大舵偏）、或接受直接力（DACS）。可选交付：
- (a) 以 A1 诚实脱靶为默认（研究展示），3-DoF 档保留原拦截演示；
- (b) 继续做自动驾驶重设计，让 A1 真正命中；
- (c) 暂时保留 divert 等效拦截作为默认演示（A3），A1 作为分析模式。

# 末段命中攻关计划（多角度）

现状：解耦 LQR + 修正气动（CNα 下限 8/rad、舵效 0.82、α 饱和 2%/deg），稳定 11/11，**脱靶 1315 m**；α≤21.7°、舵≤10.3°（未饱和）。
关键数据矛盾：重解几何需要 **~16–17 g**（divert 版 16.6 g 命中 1 m），纯气动稳定上限 **~13–15 g**，而**记录弹道自身只拉 ~10.7 g**。
→ 首先怀疑**目标几何被 `defaultSimParams` 的取整重建放偏**，其次才是气动/控制。命中攻关按下面顺序做，每步都有量化门。

## A. 目标几何对齐（P0，最高优先级）

1. 用 `scenario.json` 中目标在 664.3 s 的样本线性外推到锁定时刻 **664.54 s**，直接取真实位置/速度（不再用 bearing/range/alt 取整重建）。
2. 导弹初值同样用锁定样本（位置、速度、四元数、质量、**原始三轴角速率**，目前初值 w=0 被忽略）。
3. 校验：从记录弹道反算所需过载应回到 **~10–12 g**；若仍 >15 g，则参考系/单位有误，先查 `enuBasis`、bearing 符号、km/m。
4. 门：重解几何的 PN 峰值需求 ≤13 g；否则不得进入下一步。

## B. 制导律（P1）

1. 对比 PN / APN / 纯比例（N=3/4/5），选终端脱靶最小且指令最平滑者。
2. **LOS 率低通**（τ=0.05–0.1 s）+ **指令限幅**（≤0.8×气动可用过载）+ **指令速率限幅**（≤50 g/s），避免开局 40 g 过冲。
3. 终端 tGo 处理与盲区：tGo<0.5 s 时保持最后指令，避免噪声放大。
4. 门：指令饱和时间占比 <10%；峰值指令 ≤ 可用过载。

## C. 自动驾驶（P1）

1. LQR 增益按 **qbar/Mach 调度**（把 `wn` 做成 `wn(qbar)` 或按动压归一化），保持闭环阻尼恒定。
2. 俯仰/偏航独立增益；偏航额外阻尼（当前偏航是失稳通道）。
3. 加入**配平前馈 + 积分 + 抗饱和**；积分限幅与舵饱和联动。
4. 过载反馈与 LQR 结合：LQR 内环 + 慢速过载外环（外环带宽 ≤ 内环 1/3）。
5. 门：wn 可提到 8–10 rad/s 仍不发散；过载阶跃超调 <10%；无持续饱和。

## D. 气动数据（P1/P2）

1. 用 DATCOM/CFD 重生成 CN/CM/CNδ/CMδ（至少 M2、M6、M9 三点核对 CNα、压心、舵效）。
2. 静稳定裕度从 0.78 m 降到典型 **0.25–0.4 m**（3–6% L），同时保持舵效；否则“升力上限 ∝ 舵效×舵偏/静稳定裕度”永远不够。
3. 补铰链力矩与阻尼导数；给出 ±10–15% 不确定度带。
4. 门：`validate_aero` 全过；CNα(M) 趋势与 NACA/NASA 数据同向；静稳定裕度在 3–6% L。

## E. 执行机构（P2）

1. 二阶舵机（ωn=2π·15 Hz、ζ=0.7）+ 5 ms 延迟 + 死区 0.05–0.1° + 间隙 + 速率/行程限幅。
2. 行程从 ±15° 提到 **±20–30°**（公开舵机常见档位），直接增加配平与过载能力。
3. 铰链力矩限幅（按 §6.4 估算 ~2.5 kN·m）。
4. 门：舵机阶跃与给定二阶模型误差 <5%；无持续饱和。

## F. 质量/惯量（P2）

1. 用记录质量 1122 kg；惯量细长体 + 不确定度；CG 3.3 m。
2. 若端段确为 KW（本场景 15 km 不适用），才切 `endgameMassKg`。
3. 门：惯量 ±20% 扫掠下脱靶变化可解释。

## G. 验证闭环（P3）

1. **记录前缀匹配**：解算 vs 记录的 位置/速度 RMSE，先对齐轨迹再谈脱靶。
2. 终端脱靶 **<30 m**（目标 <10 m）。

## H. 实施顺序与回退

1. **A（几何）** → 若需求回到 10–12 g，直接复跑当前 LQR，很可能命中；这一步最便宜、收益最大。
2. **B+C**（制导+自驾）→ 把脱靶压到百米级。
3. **D+E**（气动+舵机）→ 压到 <30 m，并让饱和/裕度真实。
4. **G**（验证）→ 出报告与蒙特卡洛。

**回退**：若 A 完成后需求仍 >15 g，说明记录 payload 与重解几何不自洽；此时以 divert 版作为演示默认，纯气动版如实标注脱靶，不再用参数硬凑“假命中”。

## I. 风险

- 记录 payload 可能本身不自洽（10.7 g vs 重解 16.6 g）——A 步先证伪。
- 气动/铰链力矩无实测——D 步只能到 F2，不能宣称验证。
- 过度调参可制造“假命中”——以记录轨迹 RMSE + 蒙特卡洛为准，不以单条脱靶量为唯一指标。
- **JSBSim 无导弹模型**：主互验改 C4dynamics，弹道门用 RocketPy，JSBSim 作为可选第三路。
