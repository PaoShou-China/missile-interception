# 视觉检查与迭代记录

浏览器实测使用 Playwright + Microsoft Edge（headless，Intel UHD Graphics），窗口 1920×1080（部分迭代为 1600×900）。共完成三轮完整视觉检查，逐轮修复问题。

## 第 1 轮：几何与曝光

发现的问题：

1. 舱口盖绕世界原点旋转，飞到弹体侧外约 1.2 m 处，画面右侧出现悬空小横条。
2. 作动器偏离弹体表面，腹部整流罩是零厚度平面。
3. 白天场景严重过曝，云层接近纯白，导弹与背景混在一起。
4. 宏观机位距离过远，导弹几乎不可见，且地平线没有曲率。

修复：

- 舱口改为贴体矩形（不再旋转）；作动器贴合 r≈0.172 m 表面；腹部整流罩改为有厚度盒体。
- 降低太阳强度与半球光，环境光改为 HDRI 驱动，降低云层不透明度；按预设设置曝光。
- 宏观机位改为 120 m 级距离、44° 视场，让弹体与地平线同框。

产物：`docs/screenshots/`（旧版已覆盖，最终版见第 3 轮）。

## 第 2 轮：地球表面与尾焰

发现的问题：

1. 地球用球体 + 经纬度贴图时，贴图在掠射角被严重拉伸，出现纵向条纹。
2. 喷焰使用硬边圆锥加色混合，近景可见明显三角硬边，且与喷管脱开。
3. 夜间宏观过暗，导弹几乎不可辨。

修复：

- 地球改为自定义 Shader：球体提供曲率，纹理按可见区域的平面投影采样，远处混入大气霞色，边缘加入 Fresnel 光晕。
- 尾焰改为相机朝向的软渐变平面（椭圆径向渐变 + 沿轴线性衰减），叠加两层橙色与冷色辉光。
- 夜间提高月光与环境强度，增加相机跟随补光，抬升夜间地平线颜色。

## 第 3 轮：最终验收

- 昼/昏/夜 × 宏/中/微 9 张运行截图全部正常，无控制台错误。
- 宏观可见地表、云海与地平线；中观弹体、边条、十字尾舵与喷管清晰；微观可见面板线、作动器与舵面细节。
- 三档画质均可切换，截图/全屏/中英文/面板折叠可用。
- 离线渲染 9 张静帧与飞行动画已生成并在画廊中展示。

## 第 4 轮：加载与入口替换

问题：首次加载约 5.4 MB（三次 LOD 预加载 + 2 MB HDRI + PNG/JPG 纹理），慢网下长时间停在加载页；主站“三维探索”入口仍指向旧视景。

修复与验证：

- GLB 纹理改 WebP、HDRI 降至 512×256、云/地形改 WebP，首屏阻塞降到约 1 MB。
- 首屏仅加载 LOD0，LOD1/LOD2 首帧后预热；地形与云层独立 Suspense 流式加载。
- 主站“进入三维探索”重定向到本 Demo（带“返回学术主页”），旧视景保留在 `#/explore-legacy`，既有 E2E 合约改为访问该路由。
- 实测首帧 0.73 s、56 FPS，控制台错误 0；主站 CTA → Demo 跳转、返回链接、旧路由均可正常工作。

## 第 5 轮：原功能深度融合

问题：替换入口后，原探索器的任务面板、遥测、时间线、图表与相机入口全部不可见。

修复与验证：

- 新视景载入原平台 1504 帧验证遥测（首帧后 0.9 s 后台加载，不阻塞首屏）。
- 左侧新增“任务”：阶段徽标、飞行时钟、最高点/最大速度/脱靶量/飞行时长，7 个事件可点击跳转。
- 右侧新增“遥测”：高度、速度、马赫、动压、过载、斜距、质量、四路舵偏，以及导引头锁定状态。
- 底部时间线改为飞行时间轴：播放/暂停、拖动、1×/5×/20×/60× 倍速、事件刻度；电影模式仍保留原 24 s 镜头。
- 顶栏新增“图表”：8 组 SVG 遥测曲线，点击图表即跳转时间，Esc 关闭。
- 相机在原有宏观/中观/微观/电影/自由基础上增加“尾追”“俯视”，共 7 种。
- 实测：播放 2.5 s（20×）时间推进约 50 s，遥测数值同步变化；事件跳转到拦截 672.75 s；图表点击跳转 234 s；无控制台错误。

## 第 6 轮：地球弹道场景与三分钟电影

问题：新视景缺少原探索器的地球尺度弹道场景与 180 s 演示电影。

修复与验证：

- 移植原场景：WGS84 地球（2048/8K 昼夜贴图、云层、大气边缘）、真实 ECEF 轨迹带、发射点/目标基准标签、拦截弹与目标实体。
- 顶栏新增“实景 / 地球弹道”切换；弹道页提供地球/追逐/目标/特写四种相机，支持拖拽旋转、滚轮缩放、双击复位和跟随轨迹开关。
- 三分钟电影：669 s 任务映射到 180 s，六个分镜带字幕，支持进度拖拽、±15 s、全屏，Esc 退出；电影期间隐藏常规面板。
- 修复点火瞬间速度为 0 导致追逐相机落入弹体的问题（回退到体轴前向），并加相机补光保证夜侧可见。
- 实测：弹道场景加载后相机绕地球、拖拽/滚轮改变相机位置；电影从“点火”播到“中段”，时间 03:00 全片；返回实景正常，控制台 0 报错。

## 第 7 轮：弹体外形真实化（SM-3 参考）

问题：原弹体是通用的“细长体 + 边条 + 十字尾舵”，缺少真实型号依据。

参考公开的 SM-3 Block IB/IIA 三视图（美国导弹防御局剖面图）后调整：

- 头锥改为更短、更尖的锥形头罩，光电窗口收进锥尖。
- 移除前置鸭翼（真实 SM-3 没有）。
- 边条改为更低、更长的背/侧收线整流罩（Dorsal Harness / Strake）。
- 四片尾部控制舵面前移到 SCS 段，舵展加大。
- 新增直径略大的 MK72 式助推级（深橄榄色、分离环与两道箍带），尾部喷管与喷焰位置同步后移。
- 重新生成三级 GLB，并重渲染 9 张离线静帧与飞行动画，画廊同步更新。
- 浏览器实测中景/微距外观正常，羽流与喷管对齐，控制台 0 报错。

## 第 8 轮：鼠标视角、升力面与两场景统一模型

问题：预设相机无法用鼠标调整视角；实时画面里弹体缺少可辨识的升力面；“实景”和“地球弹道”里的拦截弹是两套不同实现。

修复与验证：

- 实景相机（宏观/中观/微观/尾追/俯视）在预设姿态上叠加球坐标偏移，支持拖拽旋转、滚轮缩放、双击复位；自由相机继续由 OrbitControls 接管，电影相机保持导演路径。
- 边条高度由 0.30 m 增至 0.40 m、尾舵半展 0.40 m、根弦 0.62 m，并保留倒角，实时画面中四片尾舵与两侧边条清晰可辨。
- 地球弹道场景改用与实景完全相同的 SM-3 GLB（`interceptor-lod0.glb`，1:1000 缩放进千米制 ECEF 坐标），删除程序化旧弹体与其前置鸭翼；两场景共用同一模型、同一遥测与同一飞行时钟。
- 实测：中观拖拽 260 px 后视角明显改变、滚轮拉近、双击复位回到预设；弹道场景特写/追逐可见同一弹体与尾舵；控制台 0 报错，GLB 请求 200。

## 第 9 轮：卡顿治理与近景抖动

问题：页面“一卡一卡”，尤其切场景、拖拽与近景时；近景视角有明显的周期性抖动。

修复与验证：

- 移除面板、时间线、弹窗上的 `backdrop-filter` 实时模糊（叠在动画画布上由 GPU 每帧重算），改用 93% 不透明纯色。
- 像素比改为上限 1.0/1.25/1.5，并加入自适应分辨率（<44 FPS 降档、>57 FPS 回升，最低 0.7）。
- 关闭 `preserveDrawingBuffer`（截图为显式渲染后同步读取）；阴影图改为约 10 Hz 更新；Balanced 去掉后期 composer 改用原生 MSAA。
- 云层由 PBR 双面三层改为无光照单面一至两层；地形分段降为 64/96/128。
- 消除 CameraRig / Entities / 轨道相机在 `useFrame` 中的逐帧对象分配；FOV 只在变化时重算投影矩阵。
- 两个场景常驻，隐藏场景 `frameloop="never"`：切换不再重建 WebGL 上下文，实测切换约 0.1 s，隐藏画布帧计数为 0。
- 近景抖动根因有两个：实景弹体姿态按 12 Hz 的 UI 时间步进（改为连续 `dataClock` 采样，并按相机距离衰减摆动）；弹道场景 60× 播放时 `simClock` 每 0.14 s 被旧 UI 时间回写而倒退（改为播放期间以连续时钟为准，并对特写相机姿态做阻尼）。
- 实测（Intel UHD，headless）：Performance 60.0、Balanced 60.3、Cinematic 50.2 FPS（优化前 60.0 / 54.3 / 40.2）；近景静止时相机逐帧位移 0；控制台 0 报错。加入卫星地表后复测为 60.0 / 60.3 / 52.2 FPS。

## 第 11 轮：播放卡顿与弹道叠层

问题：切换卫星地表后播放仍“一卡一卡”；移除弹道场景后看不到飞行弹道。

修复与验证：

- 定位卡顿主因：每张卫星瓦片到达都会把整张 2048² Canvas 上传 GPU 并重建 mipmap，一次换块 64 张瓦片 ≈ 64 次 16 MB 上传。改为“标脏 + 每 200 ms 统一 flush 一次”，并关闭 mipmap（`generateMipmaps=false`、线性过滤）。
- 瓦片重新定位从 4 Hz 降到 2 Hz，减少换块频率；图片异步解码，绘制失败自动切换 Esri。
- 新增弹道叠层：按遥测经纬度/高度在**当前弹体局部坐标系**中逐帧重建整条航迹，空中轨迹与地面投影均按地球曲率下沉；采用屏幕等宽光带（Line2）避免近处爆粗，36 个流动光点沿弧线滚动，并标注发射/最高点/拦截点。左侧“叠层”可关闭。
- 实测：20× 与 60× 连续播放 9 s，Long Task 0 次、60 FPS；弹道在 中景/宏观/末段均清晰可见；控制台 0 报错。

## 第 14 轮：面向科研展示的可信度修复

按“画面必须与数据一致”的原则整改：

- **高度可见**：地表球体改为按 `altM` 上下移动（T+0 贴地，顶点 29.9 km 下方），实测球心 y 依次为 -6 371 000 / -6 400 860 / -6 386 528 m，对应 0 / 29.86 / 15.53 km。
- **姿态真实**：弹体姿态改由遥测 BODY→ECEF 四元数换算到本地 ENU 再进场景（x 东、y 天、z 南），替换原先“按舵偏摆动”的装饰性动画；发射瞬间竖直、顶点压平。相机按机头垂直度自动拉远最多 30%，避免竖立时裁掉头罩。
- **拦截闭环**：新增目标实体（`targetSamples`）与弹目视线（虚线，锁定后转琥珀色），目标标记恒定屏幕尺寸；右侧面板增加导引头离轴角，图表增加第 9 条曲线。
- **地面投影落在地表**：投影线 y 改为 `-cur.altM - r²/2R + 20 m`（此前漏掉高度项，线浮在弹体高度）。
- **方法与数据面板**：顶栏 ⓘ 打开，展示源仓库/commit/sha256、6-DoF 引擎与 10 ms 采样、11/11 校验明细、`unreproducible-current-artifacts` 警示与原因、散布配置、关键指标、10 个观测量定义，以及本地 ENU 投影、抛物线下沉、影像来源、外形示意等免责声明；支持复制 `?t=&view=` 深链。
- **图表可引用**：每张图补时间轴刻度，新增“导出 CSV”（1504 行 × 15 列）。
- **数据驱动标题**：顶栏由写死的 “IV-2000 / 2000 km” 改为读取指标（IV-1655 / 1655 km 下程 · 顶点 29.9 km）。
- **合规与降级**：卫星瓦片主源切到 Esri World Imagery（Google 兜底）；WebGL 2 不可用时给出双语提示页而非白屏。

实测：三档 60.0 / 60.0 / 51.4 FPS，控制台 0 报错；390×844 顶栏操作区 377 px 不溢出；CSV 表头与行数核对无误；深链 `?t=0&view=meso` 能直接落在发射瞬间。

## 第 13 轮：移动端布局与观感打磨

用真实鼠标与 390×844 手机视口逐项操作后修复：

- 手机竖屏两个面板同时展开、互相覆盖，3D 画面被完全遮住；且面板折叠后把手被 CSS 隐藏，无法再打开。改为窄屏抽屉：默认收起、一次只开一个、带半透明遮罩、点击遮罩关闭，左右把手常驻可点。
- 竖屏横向视场只有桌面的一半，弹体被裁到只剩中段。相机按 `1.78 / aspect` 拉远（上限 3.4 倍），电影运镜无法拉远则改用加宽视场；同时给滚轮加 3.2 m 最近距离，避免推进弹体内部。
- 夜间弹体几乎是纯黑剪影。提高夜间环境贴图强度与半球光，增加 0.55 / 140 m 的相机补光，并在着色器里把夜间环境项从 0.26 抬到 0.62，地面不再是死黑。
- 微观/尾追视角里，整条 1200 km 弹道压缩在消失点附近几十像素内，线宽 3.4 px 的结果就是一团“涂鸦”。近景改为只显示弹体；中景/宏观保持完整弧线与流动光点。
- 地面投影线关闭深度测试（远段 600 m 抬升低于深度精度，会与地表打架成虚线），并在近景一并隐藏。
- 光点按距离淡出（中景 260 km、近景 55 km），避免远端光点堆成白块。
- 交互提示：倍速按钮补“5× / 20× / 60×”提示，折叠把手补“展开”，右侧 LOD 由 `0 / 1 / 2` 改为“0–2 就绪”。

实测：390×844 下弹体完整入画、顶栏右侧操作区 342 px 不溢出、抽屉互斥且可关闭；1440×810 桌面布局与行为不变；三档帧率 60.0 / 60.3 / 52.8 FPS，控制台 0 报错。

## 第 12 轮：抖动与闪烁修复

问题：播放时画面“一抖一抖、一闪一闪”。

逐条定位与修复：

- 抖动（一抖）主因：地表 UV 偏移此前每 0.5 s 才写一次 uniform，地面每半秒跳一格。改为每帧写入 `uOrigin/uFarOffset`，瓦片上传仍每 200 ms 批量 flush。
- 闪烁（一闪）主因有三：①纹理关闭 mipmap 后远景摩尔纹闪烁 → 恢复 `LinearMipmapLinearFilter`，因已批量上传，重建开销只落在 flush 时刻；②自适应分辨率在 44–57 FPS 间来回升降，整屏分辨率每秒变一次 → 改为“只降不升”，且需连续两个 2 s 窗口低于 48 FPS 才降 0.15 并锁定；③地面投影线与地表几乎共面产生 z-fighting 虚线闪 → 抬高 600 m。
- 换块闪白：换块前先预取新块，等到 64 张瓦片就绪 ≥85% 或超时 900 ms 才整体切换并重绘，切换过程不再混绘新旧块。
- 卫星层改为只在瓦片块内（≤235 km）生效，避免采样越过块边界被 clamp 拉伸成条纹；地表各向异性过滤提到 8×，缓解掠射角横向拖影。
- 实测（Intel UHD，headless，中景 20× 播放 15 s，900 帧）：平均帧 16.9 ms，p50 16.7 / p95 16.8 / p99 33.2 ms，>33 ms 仅 5 帧且无周期性、Long Task 0 次、DPR 恒为 1.25、相机逐帧位移 0；60× 播放 15 s 同为偶发掉 1 帧，地面无空白块/接缝，控制台 0 报错。
- 另发现 1080p 下 Cinematic 的 DPR 1.5 只有约 38 FPS（Bloom 全屏填充），而 1.25 可到约 54 FPS，故把上限收到 1.25；三档复测 60.2 / 60.3 / 53.8 FPS。

## 第 10 轮：Google 卫星背景、移除弹道场景

问题：实景背景（程序化地表与云层）几乎不动，看不出飞行速度；不再需要“地球弹道”模式。

修复与验证：

- 新增 [MapTiles.ts](../src/scene/MapTiles.ts)：按遥测 `latDeg/lonDeg` 计算 Web Mercator，取 8×8 张 z9 瓦片拼到 2048² Canvas，作为地表纹理；每 0.25 s 重新定位并在跨越 2 个瓦片时换块，纹理在场景空间按米偏移，因此地面随飞行滚动。Google 卫星瓦片为主源，失败自动切换 ArcGIS World Imagery；页面右下角显示 “Imagery © Google · Esri”。
- 地表着色器改为近处卫星影像、远处程序化地表的混合，两者都按位置滚动；中景相机改为略微俯视，默认视图即可看到地面。
- 移除 `地球弹道` 入口与 `src/orbital` 全部代码、8K 地球贴图，只保留实景模式；顶栏、左右面板、时间线相应简化。
- 保留上一轮的 DPR 自适应、按需阴影、去模糊、连续时钟与近景抖动修复。
- 实测：中景默认视图可见 Google 卫星地面，播放 2 s（20×，约 40 s 任务时间）后地表明显位移；瓦片请求全部 200，控制台 0 报错；构建体积与部署包同步减小。
