## 2. 快速开始

### 2.1 环境

- Python 3.9+（代码保留 3.6+ 语法兼容）
- NumPy 1.x / 2.x
- 可选：SciPy（Sobol 采样）、matplotlib（批量直方图）、Numba（热路径加速，不可用时自动回退）
- 测试：pytest、pytest-xdist

```bash
python -m pip install numpy scipy pytest pytest-xdist
# 可选
python -m pip install numba matplotlib
```

### 2.2 单发仿真

```bash
cd missile_intercept

python main.py                          # 助推/末段 5 ms，中制导 10 ms
python main.py --max-step 0.002         # 更细的助推/末段步长
python main.py --midcourse-step 0.005   # 中制导回到 5 ms
python main.py --duration 900           # 设置仿真结束时间
python main.py --no-plot                # 只输出 CSV
python main.py --converge               # 步长收敛 + Richardson 外推
```

启动时自动执行 `config.validate_data()`，检查参考面积、比冲、惯量、静稳定裕度、质心行程等一致性条件，不通过则抛异常。

python batch.py --cases 50 \
  --launch-cep 500 --target-cep 2000 \
  --target-alt-sigma 500 --target-mach-sigma 0.05 \
  --evade-g-sigma 1.0 --lethal-radius 10

## 4. 架构与数据流

### 4.1 状态向量

积分器维护 20 维打包状态：

```text
y = [r_m(3), v_m(3), q_m(4), ω_m(3), m_m(1) | r_t(3), v_t(3)]
      导弹 14 状态                          目标 6 状态
```

- `r_m / v_m`：ECI 位置 / 速度
- `q_m`：本体系 → ECI 四元数，标量在前 `[w, x, y, z]`
- `ω_m`：本体系角速度 `[p, q, r]`
- `m_m`：当前质量

### 4.2 多速率采样（零阶保持）

离散模块只在外层步长起点采样一次，RK4 只积分连续动力学。

| 模块 | 周期 | 配置项 |
|---|---:|---|
| 导引头 | 5 ms | `DT_SEEKER` |
| 姿态控制 + 舵混合 | 5 ms | `DT_AUTOPILOT` |
| 制导 + 交班 + 推力控制 | 5 ms | `DT_GUIDANCE` |
| GNSS 量测更新 | 1 s | `DT_GNSS` |
| 遥测 | 10 ms | `DT_LOG` |
| 导航输出延迟 | 50 ms | `NAV_DELAY` |
| 外层步长（助推/末段） | 5 ms | `DEFAULT_MAX_STEP` |
| 外层步长（中制导） | 10 ms | `DEFAULT_MIDCOURSE_MAX_STEP` |

中制导阶段实际采样率为 100 Hz，助推与末段为 200 Hz。

### 4.3 数据契约

| dataclass | 用途 | 关键字段 |
|---|---|---|
| `MissileState` | 导弹状态 | `r_eci, v_eci, q, omega_body, mass, inertia, cg_pos` |
| `NavEstimate` | 导航输出 | `r_eci, v_eci, timestamp` |
| `SeekerMeasurement` | 导引头量测 | `los_angle, los_rate, range, range_rate, is_locked, fov_angle` |
| `GuidanceCommand` | 制导指令 | `a_cmd_eci, phase` |
| `ActuatorCommand` | 舵指令 | `delta_fins(4), is_saturated` |
| `Scenario` | 单发场景 | 发射/目标经纬高、目标马赫、规避过载、种子、预置提示误差 |
| `SimConfig` | 运行配置 | 步长、模块周期、延迟、数据链、输出目录、verbose |

### 4.4 阶段状态机

```text
助推 ──(t ≥ 20 s 或 速度 > 1700 m/s 且 高度 > 20 km)──▶ 中制导
中制导 ──(交班门限连续满足 0.2 s，或强制交班)──▶ 末制导
```

交班后 0.5 s 内按权重线性混合中制导与末制导指令。

## 5. 坐标系与地球模型

- 传播坐标系：ECI
- 本体系：X 前、Y 右、Z 下
- 地球模型：默认 WGS84 椭球 + J2；`EARTH_MODEL="sphere"` 切换为半径 6371 km 球体
- 纬度：WGS84 大地纬度；经度在 `llh_to_eci` 中叠加地球自转 `ωt`
- `t = 0` 时 ECI 与 ECEF 重合

主要常数：

|---|---:|
| WGS84 长半轴 a | 6 378 137.0 m |
| 扁率 f | 1/298.257223563 |

| 地球引力常数 μ | 3.986004418 × 10¹⁴ m³/s² |

## 6. 6DOF 刚体动力学

**平动：**

```text
ṙ = v
v̇ = (R_be F_b) / m + g(r)
```

**四元数运动学：**

```text
q̇ = 0.5 · [−x p − y q − z r,
            w p + y r − z q,
            w q − x r + z p,
            w r + x q − y p]
```

每步后归一化；零四元数回退到 `[1,0,0,0]`。DCM → 四元数使用 Shepperd 鲁棒算法。

**转动（欧拉方程）：**

```text
I ω̇ = M_b − ω × (I ω)
```

**变质量与质心移动：**

```text
f = clip((m − m_dry) / (m_0 − m_dry), 0, 1)
I(m)     = I_dry + f (I_full − I_dry)
x_cg(m)  = x_cg,dry + f (x_cg,full − x_cg,dry)
ṁ = −ṁ_prop
```

干重有硬下限保护，燃料耗尽后推力置零。

## 8. 组合动力

### 8.1 固体助推

```text
F = F_sl φ(t) + A_e (P_sl − P_a)
F_sl = 130 kN，A_e = 0.196 m²
ṁ = 800 kg / 13 s = 61.54 kg/s
Isp ≈ 215 s
```

不可节流；燃料耗尽或 t ≥ 13 s 后转冲压/滑翔。

### 8.2 超燃冲压

```text
T_avail = C_R q∞ A_inlet η_M(M) η_h(h) cosα · u_thr
C_R = 6.0，A_inlet = 0.22 m²
点火窗口：1.6 ≤ M ≤ 10，q∞ > 2500 Pa
推力上限 60 kN，燃料流量上限 3 kg/s，Isp = 1500 s
```

Mach 效率 `η_M = max(1 − 0.05(M−3), 0.55)`；高度效率在 18–32 km 线性衰减，32 km 以上为 0。

### 8.3 推力控制

```text
e = M_ref − M，u_cmd = clip(Kp e, 0, 1)
M_ref = 9.5，Kp = 0.80
燃料一阶滞后 τ = 0.25 s，节流速率限制 1.5 /s
```

助推段满推，末段满推以保持能量，包线外为零。

## 9. 目标模型

3DOF 质点，定高巡航 + 末端蛇形规避。目标速度 = 目标马赫 × 当地声速，航向沿大圆指向发射点（迎头）；速度叠加地球自转牵连项。

```text
a_level = −r̂ · |v|² / |r|
a_evade = A sin(2π·0.25 t) e_cross + 0.25A sin(2π·0.5 t + 1)(−r̂)
A = n_evade g0，e_cross = r̂ × v̂
```

默认 `n_evade = 9 g`，导弹进入 15 km 后触发。

制导不再使用目标真值，而使用 `sensors/target_tracker.py` 的 6 状态估计：

- 预置提示误差 `Scenario.cue_pos_sigma / cue_vel_sigma`（默认 0）
- 未锁定：中制导数据链 1 s 修正一次（默认 200 m / 4 m/s，延迟 0.2 s，丢失率 2%）
- 已锁定：使用视线 + 距离的转换量测卡尔曼滤波

2 km 预置误差下，有数据链可恢复到十米级；关闭数据链则偏出数公里。

## 10. 导航与导引头

### 10.1 GNSS/INS

12 状态线性卡尔曼滤波：

```text
x = [r, v, b_a, b_g] ∈ R¹²
```

常加速度预测 + 一阶 Gauss-Markov 零偏；GNSS 1 Hz 更新，`H = [I₆ 0 0]`；更新后协方差强制对称。

| 参数 | 数值 |
|---|---:|
| GNSS 位置 / 速度 1σ | 8 m / 0.15 m·s⁻¹ |
| 过程噪声加速度 | 0.50 m/s² |
| GNSS 周期 / 输出延迟 | 1 s / 50 ms |
| IMU 加速度白噪声 | 0.012 m/s² @ 5 ms |
| 初始零偏 / 零偏稳定性 | 1.5 mg / 150 μg |
| 零偏相关时间 | 1000 s |

### 10.2 双模导引头

| 参数 | 数值 |
|---|---:|
| 采样周期 | 5 ms |
| 半视场角 | 20° |
| 盲区 | 200 m |
| 角度噪声 1σ | 1 mrad |
| 距离 / 距离率噪声 | 5 m / 2 m·s⁻¹ |
| 雷达参考锁定距离 | 45 km @ 5 m² |
| 雷达实际锁定（0.005 m²） | 约 8 km |
| 红外锁定距离 | 25 km |
| 失锁 / 虚警率 | 0.05 / 0.01 s⁻¹ |

```text
lock = (θ_FOV ≤ 20°) ∧ (R > 200 m) ∧ (R ≤ R_lock)
R_lock = max(R_radar, R_IR)
R_radar = 45 km · (σ / 5 m²)^(1/4)
```

闪烁噪声 `σ_glint = 0.30 × 15.7 m / R`，与角度噪声合成后经 20 ms 一阶低通得到视线角速率。

对 F-35 迎头 0.005 m² RCS，雷达仅约 8 km 锁定，红外 25 km 决定有效锁定距离；纯雷达模式下末段窗口缩到约 2.4 s，脱靶量退化到数百米。

## 11. 制导与交班

### 11.1 助推：垂直冷发射 + 重力转弯

前 2 s 垂直上升并保持姿态。爬升角速率按可用法向过载限幅：

```text
a_feasible = 0.85 (q∞ S CN_α α_max / m + T sinα_max / m)
γ̇_max = min(8°/s, a_feasible / V)
γ_ref ← max(30°, γ_ref − γ̇_max Δt)
a⊥ = V (γ̇_ref + Kγ (γ_ref − γ)) + g0 cosγ
```

总横向指令按可用过载等比缩放，最终限幅 4 g；500 m 以下加 1.5 g 拉起保护。

### 11.2 中制导：三维 Bezier + 抬升-俯冲 + 预测

```text
B(s) = (1−s)³ P0 + 3(1−s)²s P1 + 3(1−s)s² P2 + s³ P3
a_bez = k1 (p_ref − r) + k2 (v_ref − v) + p̈_ref
k1 = 2×10⁻⁴，k2 = 0.06，曲率前馈限 1.5 g
a_PN = N_mid Vc (ω_LOS × u)，N_mid = 2.0
```

- 远距离保持动压 75 kPa，对应约 30 km 巡航高度
- 下降起点按需提前（最晚 520 km，标称目标约 300 km）；切换为抬升-俯冲高度剖面：先以两段 Hermite 抬升约 1.5 km，再下压进入俯冲；受约 30 km 升力天花板限制，实际抬升量约 0.6 km
- 末端斜率约束为交班下沉角 `γ_h = −atan(1000 m / 24 km) ≈ −2.4°`，交班高度优势目标 1 km；当前单发实际交班约 1.2 km / −6.6°，存在剖面跟踪滞后
- 角度约束反馈：`a_γ = −K_γ w (V/t_go)(γ − γ_ref)`，只修正实际航迹角与剖面的偏差
- 预测项：把弹目双方传播到交班点，计算末制导 ZEM 的横向分量，按 0.2 增益提前消掉；进入 2 倍交班距离后淡出，避免与末制导 PN 抢舵
- 共面约束：`a_n = −K_cop w (6x + 4ẋ t_go) / t_go²`，K_cop = 0.8，横向限幅 3 g
- 每 10 s 重规划，150 km 内冻结路径，2 s 交叉淡入，总指令限幅 5 g

### 11.3 末制导：ZEM/APN

```text
t_go = max(R / Vc, t_go,min)，Vc = max(−Ṙ, 50)
ZEM = ρ + v_rel t_go + ½ a_T t_go²
N_eff = max(3, N [1 + 0.4 clip(1 − t_go/20, 0, 1)])
a_cmd = N_eff ZEM⊥ / t_go² − g⊥v̂
```

指令经 0.75 一阶滤波，最终限幅 40 g；当视场角超过 0.8 × 20° 时叠加软保护项。

### 11.4 交班门限

| 门限 | 条件 | 设计意图 |
|---|---:|---|
| 距离 | R ≤ 40 km | 可靠跟踪 |
| 视场 | θ ≤ 18° | 保留机动余量 |
| 前置角 | ≤ 12° | 避免大姿态重定向 |
| 剩余时间 | t_go ≥ 4 s | 完成混合与瞬态 |
| 可用过载 | ≥ 4 g | 气动权限足够 |
| 高度差 | 0–12 km | 保留俯冲能量 |
| 速度 | ≥ 1800 m/s | 能量门限 |
| 锁定 | 已锁定 | 硬捕获 |

所有门限连续满足 0.2 s；30 km 内高度门限无法满足时可强制交班。交班后 0.5 s 权重混合：

```text
a = w a_mid + (1 − w) a_term，w = clip(1 − (t − t_trig)/0.5, 0, 1)
```

## 12. 控制与舵机

```text
a_cmd(ECI) → 虚拟 α/β → 二阶指令预滤波 → 角速率内环 → 虚拟舵偏 → 舵混合
```

- 虚拟攻角限幅 ±25°，攻角包线 20°（超出包线时参考回拉，不继续追指令）
- 侧滑按“微调通道”处理：参考限幅 8°@70 kPa，并按 √(q∞/70 kPa) 放大到全包线；超出 12° 包线时反向回收
- 预滤波阻尼 0.707，带宽随 √q∞ 调度，1–10 Hz
- 外环 Kpα = 6.0，Kiα = 0.75；Kpβ = 3.6；内环 Kpq = 0.14，Kpp = 0.035
- 增益随动压调度：`gain_scale = clip(Kp,req / Kp,baseline, 0.30, 3.0)`，ωq = 22 rad/s
- 滚转指令：4/s 角度对齐 + 0.25 s 一阶平滑；α > 15° 时按 15°/α 降额，抑制 α·p 侧滑耦合
- 直接过载内环：n_z PI + 0.06 s 超前补偿
- 抗积分饱和、位置饱和反算、q∞ < 100 Pa 时冻结积分

四舵十字混合：

```text
δ_up = δ_down = δ_Y
δ_left = δ_P − δ_R
δ_right = δ_P + δ_R
```

处理顺序：速率限幅 → 一阶滞后 → 位置限幅。舵偏 ±25°，舵速率 150°/s，舵机时间常数 10 ms，饱和标志反馈给抗饱和。

侧滑包线的作用：侧力通道比升力通道弱约 3 倍（CY_β = 1.6 对 CN_α ≈ 5），巡航动压下仅 0.2 g 的横向需求就需要 >10° 侧滑，副舵先饱和，十字混配随即失去滚转权限，机体在高攻角/大侧滑状态被 α·p 耦合推出包线，阻力激增导致能量耗尽、飞越目标。把横向载荷交给“滚转后的升力平面”后，几何套件中的 172.6 km 飞越降到 5.3 m。

## 13. 数值积分与遥测

- 原生 RK4，四阶定步长，返回加权平均导数供 INS 缓存
- 步内状态重构：从区间左端重新跑一次 RK4，避免端点 Hermite 插值在推力/舵跳变处的误差
- 事件：脱靶（距离率负转正）、落地（|r| = Re）；方向感知判零 + 二分定位，容差 1e-10
- 可选 RK45 仅作连续系统参考解
- 遥测预分配 NumPy 缓冲，禁止 `list.append`；时间严格递增；NaN/Inf 立即抛错
- Numba 热路径可选，缓存键绑定源码哈希

## 17. 假设与适用范围

### 17.1 主要假设

1. WGS84 椭球 + J2 引力，不含地形；可切换 6371 km 球模型
2. 默认无风、无大气扰动；`vehicle/wind.py` 为可选风模型
3. 目标为 3DOF 质点，固定迎头 RCS，无姿态/频率起伏
4. 气动系数为 DATCOM + 理论外推，未经本飞行器风洞/试飞标定
5. 导引头为简化双模模型，不含杂波、干扰、多径、云衰减与信号处理链
6. 舵机为一阶滞后 + 速率/位置限幅，无间隙、死区、结构柔性
7. 惯量与质心随燃料线性变化，忽略推进剂晃动
8. 推力为工程模型，不含燃烧不稳定、进气道起动/喘振
9. 未建模气动加热、结构强度、热防护与气动弹性
10. 未建模数据链组网、协同交战与飞行中指令更新

### 17.2 适用范围

**适用**：制导/控制/导航算法设计与对比、弹道方案权衡、能量管理研究、蒙特卡洛脱靶量统计、软件架构与测试方法验证。

**不适用**：系统性能鉴定、作战级命中概率评估，或任何实弹运用决策。
